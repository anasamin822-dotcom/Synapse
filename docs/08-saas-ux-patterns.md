# 08 — SaaS UX patterns applied (his standing 20-pattern rule, Nov 6)
Applied (15): optimistic UI (mark revised, task toggle/add), skeleton loaders (boot screen + table filter transitions), command palette, persistent sidebar nav, loading & empty states (table "all caught up", empty plan), autosave (notes + all state), debouncing (palette search, task validation), throttling (scroll-spy), smart form validation (onboarding + add-task, inline errors), bulk actions on list, reusable data table, advanced filtering (subject + priority), keyboard shortcuts (Ctrl/Cmd+K, N, ?, Esc), mobile-optimised layouts (bottom nav, stacked bento, safe-area), destructive action protection (reset confirm), graceful error recovery (corrupt localStorage -> defaults + toast), custom 404.
Skipped as meaningless for this demo (3): tier-based UI indicators (no plans), referral/affiliate pages, onboarding data capture kept but minimal.
