# 07 — Features
1. Onboarding (name + target exam + date) stored locally, skippable. 2. Hero with greeting, exam countdown chip.
3. Animated stat counters (hours, due, streak, cases). 4. Revision table: subject chips + priority filter, bulk select + mark revised, per-row done, overdue labels.
5. Clinical case card: progressive reveal of workup steps, 3 rotating fictional cases. 6. Today's plan: add/complete/delete with duplicate guard, progress ring.
7. Weekly hours bar chart (CSS). 8. Autosaving quick note. 9. Command palette (Ctrl/Cmd+K) with actions + topic shortcuts. 10. Keyboard shortcuts + help modal.
11. Reset demo with confirm dialog. 12. Custom 404 page.
