# Synapse

A light, responsive medical-student study dashboard UI demo, built with HTML, CSS and JavaScript. No dependencies or build step.

## Run locally

Run `python3 -m http.server 8000` and open the local address shown in your terminal.

## Features

- Revision table with subject and priority filters, selection and bulk completion
- Fictional clinical cases with progressive disclosure
- Study planner, weekly chart and notes
- Command palette, keyboard shortcuts and mobile navigation
- Device-local storage with a clear session-only fallback

All cases, names and numbers are fictional sample content. Not medical advice. No AI service, backend, authentication or medical-record handling is claimed.
